# Ретрит с Мастером Камильпашой в DOMA · 9–17 мая 2027

Статический сайт на HTML, CSS и JS, собирать ничего не нужно. Чтобы посмотреть, откройте `index.html` в браузере.

## Структура

```
index.html              — главная страница (RU и EN тексты рядом)
apply.html              — анкета участника (своя страница, ответы уходят в Google-форму)
assets/css/styles.css   — оформление сайта (цвета — в начале файла, :root)
assets/css/apply.css    — оформление анкеты
assets/js/main.js       — язык, меню, анимации, видео, фото в лайтбоксе
assets/js/apply.js      — вопросы анкеты и отправка в Google-форму
assets/img/             — фото (WebP); retreat/ — фото прошлого ретрита
assets/video/           — видео:
    hero.mp4 / hero-mobile.mp4    первый экран, ~27 с по кругу: дрон (Bird View) → 2 сцены йоги → Мастер в зале → улыбка → гитара → Мастер → люди в зале
    arch.mp4                      арка в блоке «Место» (Glamps — лес и шатры)
    final.mp4 / final-mobile.mp4  фон финального блока, ~18 с: дрон (Quinta 2) → вывеска DOMA → терраса → лаунж → сад → группа
tools/make-hero.sh      — нарезка одного видео для первого экрана
```

## Как править тексты

Каждый текст записан дважды:

```html
<span lang="ru">Заполнить заявку</span><span lang="en">Fill in the application</span>
```

Меняйте оба варианта. Язык переключается кнопкой RU/EN, ссылка с `?lang=en` открывает английскую версию.

## Анкета

- Все кнопки «Заполнить заявку» ведут на `apply.html`. Анкета разбита на 4 шага, черновик сохраняется в браузере. После отправки ответы попадают в ту же Google-форму и таблицу.
- Вопросы описаны в `assets/js/apply.js` в массиве `STEPS`. Подписи (`ru`, `en`) можно менять свободно.
- Значения вариантов (`v`) должны совпадать с Google-формой слово в слово, иначе Google не примет ответ.
- Если в Google-форме добавить или удалить вопрос, нужно обновить `STEPS`: у нового вопроса будет новый номер `entry`.

## Текущие решения

- **Цены** как в прошлом году: билет 550 €, организационные расходы 650 €, онлайн 450 €, номера 175/150/120 € за ночь, частное занятие 100 €/ч.
- **Сроков приёма заявок** на сайте нет.
- **Превью ссылки.** После публикации укажите в `og:image` полный адрес картинки, например `https://домен/assets/img/og.jpg`, чтобы в Telegram и WhatsApp появилось превью.
