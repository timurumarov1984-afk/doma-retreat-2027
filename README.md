# Ретрит с Мастером Камильпашой в DOMA · 10–17 мая 2027

Статический сайт на HTML, CSS и JS, собирать ничего не нужно. Чтобы посмотреть, откройте `index.html` в браузере.

## Как править тексты

Каждый текст записан дважды:

```html
<span lang="ru">Заполнить заявку</span><span lang="en">Fill in the application</span>
```

Меняйте оба варианта. Язык переключается кнопкой RU/EN, ссылка с `?lang=en` открывает английскую версию.

## Анкета

- Все кнопки «Заполнить заявку» ведут на `apply.html`. Анкета разбита на 4 шага, черновик сохраняется в браузере. После отправки ответы попадают в ту же Google-форму и таблицу.
- Вопросы описаны в `assets/js/apply.js` в массиве `STEPS`. Подписи (`ru`, `en`) можно менять свободно.
- Значения вариантов (`v`) должны совпадать с Google-формой слово в слово, иначе Google не примет ответ.
- Если в Google-форме добавить или удалить вопрос, нужно обновить `STEPS`: у нового вопроса будет новый номер `entry`.

## Уведомления о заявках в Telegram

Скрипт `tools/telegram-notify.gs` работает внутри Google-формы анкеты. На каждую новую заявку бот присылает в Telegram сообщение со всеми ответами и ссылкой на таблицу. Сейчас получатель — `@verak_` (строка `RECIPIENTS` в начале скрипта, можно указать нескольких через запятую).

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → придумайте имя. Он пришлёт токен вида `123456:ABC…`. Никому его не пересылайте и не кладите на сайт.
2. **Получатель жмёт Start.** Каждый получатель открывает бота по ссылке от BotFather и нажимает «Start» — без этого бот не может написать первым.
3. **Скрипт.** Откройте Google-форму анкеты → ⋮ → «Редактор скриптов». Удалите всё в `Код.gs` и вставьте содержимое `tools/telegram-notify.gs`. Сохраните.
4. **Токен.** В начале скрипта вставьте токен бота между кавычками в строке `var BOT_TOKEN = '';` (только в редакторе скриптов формы, не в этом файле — сайт виден всем). Сохраните.
5. **Включить.** Вверху выберите функцию `setup` → «Выполнить» → разрешите доступ своим Google-аккаунтом. В журнале появится «✓ @verak_ найден(а)».
   Если написано «не найден(а)» — получатель ещё не нажал Start: пусть нажмёт, затем выполните `findChats`.
6. **Проверка.** Выполните `sendTest` — в Telegram придёт последняя заявка с пометкой «Тест».

Чтобы добавить получателя: допишите ник в `RECIPIENTS`, он(а) жмёт Start у бота, затем выполните `findChats`.
